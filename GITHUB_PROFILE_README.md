### Pharmacy Assistant

AI-powered pharmacy platform built as a full-stack, multi-tenant product demo.

**Live demo:** https://pharmacy-assistant-demo.onrender.com  
**Repository:** https://github.com/72rs3/pharmacy-assistant

**What I built:**

- Customer storefront with AI assistant and product/medicine search.
- Owner portal for inventory, products, orders, appointments, prescriptions, and escalations.
- Platform admin page for pharmacy management.
- Multi-pharmacy tenant resolution so each pharmacy has isolated data.
- OpenRouter-powered AI routes with RAG and safety guardrails.
- Cart and checkout flow with prescription-required medicine handling.
- Docker-based deployment to Render with stable demo data.
