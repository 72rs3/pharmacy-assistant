## Featured Project: Pharmacy Assistant

**Live demo:** https://pharmacy-assistant-demo.onrender.com  
**Repository:** https://github.com/72rs3/pharmacy-assistant  
**Stack:** React, FastAPI, SQLAlchemy, PostgreSQL/SQLite, Docker, Render, OpenRouter, RAG

### What I Built

- Customer storefront for medicine/product discovery.
- AI assistant connected to pharmacy data, chat history, safety rules, and RAG.
- Owner portal for inventory, products, orders, appointments, prescriptions, and escalations.
- Platform admin page for managing pharmacies.
- Multi-tenant architecture so each pharmacy has isolated data.
- Cart and checkout flow with prescription-required medicine rules.
- Stable Docker/Render demo deployment with seeded test data.

3. Ask `price?` in the same chat to test conversation memory.
4. Add Panadol to the cart.
5. Search for `promethazine` and test prescription-required checkout behavior.
6. Log in as Sunrise owner and inspect inventory, products, orders, appointments, prescriptions, and escalations.
7. Log in as platform admin and inspect pharmacy management.
