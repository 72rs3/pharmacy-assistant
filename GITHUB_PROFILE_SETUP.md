# GitHub Profile Setup

This file explains how to turn `GITHUB_PROFILE_README.md` into the public GitHub profile page shown at https://github.com/72rs3.

## Required GitHub Repo

Create a public repository named exactly:

```text
72rs3
```

The full repo will be:

```text
https://github.com/72rs3/72rs3
```

GitHub only displays a profile README when:

- the repository name matches the username exactly,
- the repository is public,
- the root file is named `README.md`,
- the README has content.

## File To Upload

Use this file as the profile README content:

```text
GITHUB_PROFILE_README.md
```

When the repo exists, copy that content into:

```text
72rs3/README.md
```
